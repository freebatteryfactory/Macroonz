# Codec mutation crossing

This lane observes the mutation adapter's codec-order completion through independently compiled Rust.
The unchanged codec and each selected source are produced by the same codec owner, while expected wire bytes are authored here independently.
Homogeneous member swaps compile and fail that witness; heterogeneous assembly swaps can refuse compilation.
The lane distinguishes those outcomes and makes no harness activation, interpreted-trust or proposal-admission claim.
Generated subjects and binaries remain disposable under the shared rustc specimen helper's Cargo-owned storage.
