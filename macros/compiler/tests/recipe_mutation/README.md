# Recipe mutation source and behavior

This lane materializes transition-target and effect-binding alternatives with the ordinary recipe compiler and executes the resulting Rust through the shared specimen observer.
The subject declares a small event relation; independently written assertions require the first event to reach its expected state and perform its expected effect.
Each changed source must compile before the corresponding behavioral witness objects.
Wrong sites, absent alternatives and unavailable targets refuse explicitly, while a restatement preserves the ordinary bake's canonical account and emitted bytes.
Consuming source supplies a lawful twin for a substituted effect whose payload type fails rustc, separately from a substitution rejected by the existing binding constructor.

These controls observe generated-program behavior separately from selection of source material.
They do not establish harness activation, selection-specific trust, survivor admission or an automatically generated oracle.
