# render

This home projects one informed recipe into generated Rust through the one capability that standard and caller-owned projectors share.

The door binds the built-in catalog to the outputs prepared for one recipe walk and dispatches each selected role to its renderer.
Each child renders one projection: companions, dispatch, typed relation tables, typestate, codec, and the two evidence bridges.
The token seat owns the spellings every renderer writes, so a path, a derive, or a public marker is composed once.

Nothing here decides what a recipe means.
Selection, subjects, and dependencies were settled by the recipe declarations' nucleus before any renderer runs, and a renderer that cannot fill its role returns the projection refusal instead of inventing a fallback.
