# text

This home is the callable text producer: the third road into the normalized captured tree beside the compiler host and a test.

The declarations hold the source-byte magnitude, the lexical causes the pinned low-level lexer can establish, the refusal a text read carries with the byte it sits at, and the capture the read produces together with the byte offsets that resolve every handle it issued.
The read checks the source-byte magnitude before tokenization, lets the low-level lexer own token boundaries, slices every spelling from the original source by the reported byte range, and sends every retained token through the checked builder.
The contracts render every refusal as one sentence about declared text and project a refused read as an intrinsic diagnostic at the byte coordinate it established, so no caller can pair it with a different coordinate or refusal vocabulary.

The low-level token roster is answered exhaustively at five distinct questions:

- capture chooses the complete action or refusal for one token;
- punctuation decides whether adjacency joins one punctuation mark to the next;
- opening delimiters map to the group and closer they introduce;
- closing delimiters answer whether an unopened closer has arrived;
- a current closer answers whether it closes the particular group being held.

These partitions remain separate because the first four classify one token for different operations while the fifth also depends on the currently held group.
A universal classification table would erase that contextual distinction and make one owner answer questions it does not possess.

Text never synthesizes an invisible group, because text that carries no delimiter carries no group.
The coordinate a refused read answers in is composed beside every other coordinate the capture seam hands out, in the capture home's resolve road.
