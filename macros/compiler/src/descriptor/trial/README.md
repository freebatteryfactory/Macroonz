# `trial` — the kind that carries declared rows into a test target

One authored declaration in; one stamped module out, delivered as cargo the consumer's test target invokes.

## What an author states

Descriptor meaning, and nothing else.

The support name a consumption target invokes, the module the stamp writes, the table's own name, each aggregate seat and the execution suite it selects on, and each row's lens, claim, roles, tags, subject, check, and population.

The helper attribute those clauses are written in is the caller's word, not this home's. A door registers the attribute it wants and hands the same [`Grammar`](crate::descriptor::Grammar) to the reading, so a refusal names what an author actually typed.

## What an author cannot state

Two things, and both absences are structural rather than reviewed.

**The producer's own act.** The door a declaration came through, the producer that emitted the table, and the projection that emitted the rows are composed inside the rendering from the [`Emitter`](crate::descriptor::Emitter) the caller declares. A seat that took one would let an authored declaration sign an act these services performed.

**The consumption target's host facts.** The two revision commitments, the callable that reaches a row's conclusion, the declared budgets, the target and toolchain the runs stand on, and the clock live in the test target that invokes the carrier — which is not the crate the declaration sits in and has no crate binding a rendered path could be rooted at. They arrive as expressions at the invocation, where that target's own hygiene reaches its own items.

## The suite is the group's

A row states no execution suite. One aggregate seat selects on one suite, every row grouped under it runs under that one, and the pairing a stamp cannot check at expansion is one no declaration can get wrong.

The alternative — a suite on every row — is two lawful spellings that can disagree, producing a seat that selects none of its rows while every constructor on the road admits them.

## One namespace, closed once

Seats and lenses are both functions in the module the stamp writes, so they share one namespace. It is closed at the payload and nowhere else: the whole namespace is visible there, and a uniqueness law standing in two homes is one law that agrees with itself until one home is edited.

## The row expression is a block

The binding constructor's whole job is to establish that a row's subject route and check reference are the attachment's. A rendering that parsed each name twice would hand it two separately parsed values, and the check would pass because two parses of one spelling agree — which is a different statement from the one the constructor was written to make.

One parse, two readers, and the agreement is structural.
