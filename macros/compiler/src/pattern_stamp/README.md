# `pattern_stamp` — coupled-seat construction

This home renders and accounts for the coupled-seat stamp used by collection-shaped refusal families.

## The coupled seat

A collection-shaped refusal body carries one private admitted-prefix seat and exposes only the readers and construction road declared for that family. The stamp emits the seat inside a closed module and re-exports the family at the caller coordinate, making the generated module the complete set of roads that can reach the private field.

## Publication

The rendered artifact carries typed insufficiency grounds for the publication road: one definition must be shared across files, and the generated module and macro names must be stable inputs to those files. The publication record is the compiler's statement of the unit, staged digest contract, and manifest; it is not an external receipt.

## Seats

`types.rs` owns the coupled-seat declaration, rendering inputs, publication record, and bounded refusal families. Its child `type_guard.rs` owns all construction roads to private seats. `type_contract.rs` owns the visibility and mint-form mappings. `plan.rs` reads a retained pattern-stamp plan into its artifact statement. `render.rs` emits the front grammar, internal arms, seat module, and invocation.
