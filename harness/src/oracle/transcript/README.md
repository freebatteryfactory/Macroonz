# transcript — an independently composed preimage

This home writes a published preimage grammar from typed caller arguments and derives the identity that grammar names.

Its member roster is the closed set of framing decisions the method can make.
No field order, framing, or spelling is imported from the producer whose identity is under judgement.

A derivation context is assembled from indivisible caller-supplied segments.
Empty segments and segments that already contain the context separator are refused so different segment rosters cannot spell one context.

The digest mechanism is deliberately shared with the producer while the preimage construction remains independent.
The verdict establishes parity for that published grammar and no stronger independence claim.
