# compiled — compiler-resolved behavior

This home compares a caller-reported compiler observation with behavior the caller declared independently.

A compiler can establish that paths resolve, implementations are coherent, constants evaluate to typed values, or an artifact is refused.
This home never invokes a compiler and therefore never claims provenance for an observation supplied to it.

The observed roster preserves duplicates because a repeated read-back is a finding.
The declared roster refuses duplicate names before it exists so one expected member never has two authorities.

The verdict says nothing about how an accepted artifact was written.
That remains the structural method's question.
