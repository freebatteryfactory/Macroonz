# input

One specimen crosses this home as exact bytes under an independently expected profile, then becomes a typed value through an explicitly bound decoder.

The profile names the caller's input convention, its version and its schema address.
The caller owns that convention and the schema's meaning.
An envelope commits to those facts and the complete specimen, so changing a specimen changes its case identity without renaming a reusable trial or a defect.

## Admission

The reader receives the expected profile and resource limits separately from the envelope.
It bounds the envelope before hashing or allocating, verifies its content claim, checks the profile and schema, and refuses incomplete framing or trailing bytes.
The payload limit is checked before copying the specimen.
The writer obeys the same limits.

A decoder binding carries its profile, revision and capture-free callable.
It admits a typed value only after the callable succeeds and consumes the complete specimen through `arbitrary::Unstructured`.
The returned value retains the envelope and decoder revision that produced it.
The callable owns semantic decoding, including its own work and allocation policy; a byte limit does not prove that arbitrary caller code terminates or bounds its allocations.

## Authority

An admitted input is data, not an execution or a verdict.
Its content address establishes byte integrity relative to a claim, not the identity or honesty of a writer.
Storage, generation order, population accounting, execution and historical-record custody belong to their existing owners.
No function pointer, ambient registry, mutable scratch slot or live host capability is serialized.

Profile names are resolved against the independently supplied admitted name.
Foreign strings never become static names, and no interner or allocation address enters identity.
