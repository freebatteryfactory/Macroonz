# census

A closed accounting must grow when the roster of things it counts grows.

This private home owns the stamp that binds a census's storage and saturating increment operation to one declared seat roster.
Each semantic owner still decides what event belongs in each seat, which readings are public, whether a total is meaningful, and which contextual values travel beside the counts.

The stamp supports both array storage and named-field storage because those derived `Debug` shapes are already distinct public observations.

## Authority ceiling

This mechanism counts only the exact seat and amount its caller supplies.
It does not classify an event, invent a verdict, decide whether a count matters, or turn an accounting into evidence.
