# `work` — counted curves and the owner's judgment

This private child owns the work a benchmark callable may record and the judgment an owner may make over the measured and planted-worse curves.

The recorder is scoped to the observation roster declared by the row's executable attachment.
It refuses unknown observations and arithmetic overflow rather than inventing or wrapping work.

The judge sees the declared formula, complexity claim, budgets, and both primary curves together.
It never sees a clock reading.
The planted-worse control must refuse and satisfy the declared exact gap before the measured curve can qualify.

`types.rs` owns the work, judgment, recorder, and attachment vocabulary, `type_guard.rs` owns their invariant nuclei, and `measure.rs` records primary curves and invokes the owner judge.

The child is private.
The parent [`crate::bench`] door preserves every public path and owns host execution.
