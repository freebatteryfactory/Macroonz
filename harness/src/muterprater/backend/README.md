# backend

The typed reading and custody of pressure imported from an external mutation backend.

This home owns the adapter profile, exact command and source custody, grammar qualification, and generic suite-bite ceiling.
Its `wrap` operation reads and plans imported backend output.
The parent mounts that operation at `macroonz_harness::muterprater::wrap` while this backend home remains private.
It neither executes a backend nor acquires evaluation-pair or selection authority.
