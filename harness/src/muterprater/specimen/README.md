# specimen

Specimen owns exact compiled observations and rejection pressure over separately materialized production-shaped projections.

This home owns compiler-source content identity, materializer and host bindings, compiled specimen requests and observations, and the standing and refusals of exact projection pressure.
The public `muterprater::specimen` module is its operation door, while its types remain available through the parent `muterprater` type surface rather than a public child ontology.

Specimen consumes discovery's surface, selection, and directive vocabulary, interpretation's pair, parity, and witness vocabulary, and verdict's mutation vocabulary through their parent compatibility paths.
The ordinary observer consumes passive pair standing and an admitted observation scope without a prior parity judgment or selected rejection.

`observe_mutation` binds bytes-only artifact identity, source role, pair standing, invocation profile and target before retaining both host outcomes.
The request is independent of any later witness identity.
Host failures remain beside reached meanings; materialization failure refuses before host execution, and identical unchanged/selected source cannot claim a materialized damage.
`demonstrate_compiled_projection` uses the same materializer and host observation operations, then requires its retained witness to pass the baseline and reject the selected result.
Its pressure binds those reports to the exact selection and witness execution.
Successful pressure owns the exact unchanged and selected source buffers handed to the host, so later inspection needs no materializer or host call.
It records what the host reports and does not claim to observe the host's process.
Wrapped-backend pressure is a separate evidence book and cannot substitute for exact compiled specimen pressure.
