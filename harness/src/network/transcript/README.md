# transcript

A transcript binds source-specific material and delivery lineage to one content address.

This home owns live-recorded and simulated source postures, the exact body encoding, owner-built reading, simulation reproduction, playback exhaustion, and the same-address join between reproduction and replay.
It consumes the sibling simulation through its established public operations and a private retained-value crossing; it does not own topology, schedules, fault semantics, or delivery behavior.

Writing and reading both admit rows against the owner-built topology before a pack exists.
Reading never mints names from foreign bytes.
Simulation standing is earned only by executing the retained byte-valued action manifest through `SimNet<Vec<u8>>` and comparing every resulting row with the addressed roster.

Playback hands out exactly the addressed rows at their recorded ticks.
Exhaustion claims only that every row was handed out, and its join with reproduction claims only that both values name the same transcript.
