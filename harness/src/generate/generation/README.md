# generation

The input-generation owner turns a declared search into deterministic structured inputs and a complete accounting of every case it reaches.

The byte source is seekable and derived only from declared identity material.
Changing how far a search runs re-windows the same stream, while caller-supplied bytes remain exactly the material the caller supplied.

The shared driver draws bounded cases, asks the owner's decoder for commands, applies the owner's population precondition, and retains both admitted sequences and every reached disposition.
The census and halt remain separate so a stopped search cannot hide work it already attempted.

This home does not execute commands, judge observations, reduce failures, or assign replay authority.
The exact plan fields, source preimages, bounds, disposition roster, and callable contracts live with their public items.
