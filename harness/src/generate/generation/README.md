# generation

The input-generation owner turns a declared plan into a deterministic sequence drive and a complete generation census.

A plan binds one population, one generation profile, one declared byte origin, two budgets, one rejection allowance, and one size progression.
The source address is derived only from the population, profile, and origin, so changing a drive budget or progression does not rename the byte stream.
Derived chunks are independently addressable by the source address and chunk counter; supplied bytes remain exactly the caller's material.

The driver draws at the plan's requested width, decodes until the case is spent or the decoder refuses, applies the population precondition, and counts the resulting disposition.
Every reached case occupies exactly one census seat.
The halt records the bound or decoder contract event that ended the drive.

This home does not execute commands, judge observations, reduce failures, or assign replay authority.
