# producer field

The harness publishes canonical field rosters for the producer vocabularies it admits.

This home owns the authored mutation-discovery and benchmark rows.
Each row keeps its field name, shape, and cardinality together before the descriptor home projects it into the public schema surface and canonical root identity.

## Authority ceiling

The bank states producer-facing vocabulary only.
It does not own the runtime values that cross those fields, admit a delivery, derive schema identity, or decide what any producer observation means.
