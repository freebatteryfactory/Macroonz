# Recipe economics — final-source work curves through the benchmark owner

This crossing binds final recipe work to the existing benchmark vocabulary rather than inventing another cost schema.

It varies vocabulary size, relation density, exact-signature generic complexity, projection count, and repeated callable-compiler invocation.
Every retained coordinate is rebaked during correctness preflight, recorded as typed work, and paired with a control that repeats the complete observation twice.

The test establishes deterministic work counts and generated-byte movement for the exact source revision.
Its deterministic clock only proves benchmark choreography, so it makes no host-time, memory, asymptotic, cross-platform, or universal performance claim.
