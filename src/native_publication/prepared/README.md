# Prepared publication

This home joins physical file bytes to one complete sealed publication inventory.
The unformatted route preserves the source projection already admitted by that inventory's shared count and byte bounds.
The formatted route requires exactly one actual successful formatter output for every expected path and imposes a separately declared aggregate physical-byte bound.

Each formatter output must retain the exact original source and canonical commitment expected at its path.
Missing, foreign, duplicate, refused or crossed-source outputs cannot create a prepared set.
Input ordering has no authority: the prepared files follow the original publication order.
An empty publication admits an empty physical set.
File views retain their distinct canonical and physical commitments, and the original inventory and formatter observations remain inspectable.

Prepared material supplies no staged compilation, destination ownership or installation evidence.
Its byte allowance bounds retained publication source, independently of per-process capture limits and formatter configuration.
