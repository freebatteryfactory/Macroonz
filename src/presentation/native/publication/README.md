# Publication presentation

This home projects the [publication command](../../../native_publication/command/README.md) and its existing inventory, formatter, preparation, staging and destination records.
The complete file roster retains declared order, landing names, logical unit references, canonical token bytes and separately prepared physical bytes and commitments.
These are publication views rather than a serialization of the compiler's entire expansion account.
Formatter observations retain their original source, command, version, configuration, captures and admitted text or refusal.
Staged compilation reuses the native compiler projection and keeps compilation, source and dependency refusals distinct.
Destination checks retain every discrepancy, including several observations at the same path, and read `is_current` from the destination owner.

Command outputs preserve the distinction between declared, prepared, checked, generated and recovered values.
Generated output retains the compiled publication carried by that variant; it supplies neither an installation receipt nor a fresh destination check.
The public output enum can be assembled by a caller, so its variant does not independently establish that the command ran.
Recovery has historical standing and contains no fresh compilation observation.
Command errors retain their typed phase, any completed formatting prefix or compiled publication, and whether cleanup remains pending.
Pending formatter and compiler values expose their existing public cleanup observation; their private source context remains with the original resource owner.
Presentation borrows these owners and neither finishes cleanup nor releases workspace custody.

The caller's generic declaration error is rendered through its own `Debug` implementation, the same bound used by the command error's existing display contract.
That text is labelled caller-owned debug output, escaped without interpretation and never treated as a native error, semantic verdict or structured encoding of the caller's private fields.
Formatting caller text invokes that caller-supplied implementation; this home itself invokes no generator, formatter, compiler, filesystem operation or recovery step.
