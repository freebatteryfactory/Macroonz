# oracle — displayed compiler observations and judgments

This home projects the [compiled oracle's](../../../harness/src/oracle/compiled/README.md) supplied observations and existing verdicts.
An observation and a comparison remain separate records: a conforming refusal is still a compiler refusal, and a caller-reported observation does not establish a compiler invocation.
Exact comparison differences retain the owner's code and primary coordinates; member differences retain the member name the verdict actually carries.
Read-back preserves value variants, order, repeated members and empty series without decoding bytes or recomputing a verdict.

`archived_oracle` displays the [oracle archive](../../../harness/src/oracle/archive/README.md) with its method and historical address.
Vector differences keep both entire buffers and their derived first difference; transcript differences keep unequal digest claims without their absent preimages.
Structural positions remain historical numbers rather than indexes into a current source, and free member text remains exact.
An archived conforming verdict carries no successful-case material or current observation that its owner did not retain.
