# benchmark — display of reached work and separate refusals

This home projects the [benchmark owner's](../../../harness/src/bench/README.md) reports and refusals through the shared [presentation formats](../README.md).
It retains authored row order, complete declarations, preflight reports, both primary curves, all three judgments and any reached secondary work and measurements.
An unreached observation is null, never an invented successful observation.
Historical projections retain their archive standing and cannot qualify a current run.

`benchmark_refusal` displays why no report was produced, while `benchmark_verdict` displays the owner's first refusal from an existing report.
`benchmark_archive_refusal` preserves the [archive owner's](../../../harness/src/bench/archive/README.md) nested framing, declaration, population and producer-standing causes.
Neither replaces the complete report with its first refusal or computes a new benchmark judgment.
Names and cause text remain caller-owned data, and a failed clock remains separate from semantic work qualification.
