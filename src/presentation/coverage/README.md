# Coverage presentation

This home projects the [coverage owner's](../../../harness/src/fuzz/README.md) readiness, candidate results, novelty decisions, accumulated frontier and typed refusals.
The original request, canonical source map, established compiler facts and every campaign ceiling remain distinct.
Candidate bytes, execution classification and complete canonical points remain visible even when execution cannot earn novelty.
The frontier retains attempted-work counts and interesting inputs in admission order; it carries no per-attempt history that presentation could reconstruct.

Coverage is a search signal and supplies no semantic oracle or defect verdict.
Reading these values performs no process execution, source mapping, frontier admission or cleanup.
Native failures additionally preserve the [native projections'](../native/README.md) finished or pending process state and the coverage case directory still awaiting cleanup.
