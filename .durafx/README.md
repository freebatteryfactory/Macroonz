# durafx

This directory holds the compact accepted receipts that record an externally observed fact no executable owner can retain.

One release owns one page under `package/<release>/receipt.md`.
A page records exact revisions, blob identities, hashes, hosted run identifiers, registry checksums, and the reconstruction road for anything it names, and it grows only when the observation it adds has its own authority.

Nothing here restates repository law, and nothing here is a warehouse.
Raw campaign output, build logs, package caches, and copies of tracked source stay out; a page names the revision and blob that Git already owns instead.
The rule that decides what belongs here is the evidence law in [`AGENTS.md`](../AGENTS.md).
