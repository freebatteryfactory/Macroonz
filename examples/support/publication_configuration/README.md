# Publication example configuration

This home admits the shared native command fields used by the publication examples through the existing root publication and process constructors.
Each caller supplies its publication allowance, authored compilation fixture and executable stem; its values, kind, renderer and independent expected answers remain in that example.
The crate's `input` module supplies the existing bounded JSON field and explicit environment readers.

The adapter preserves unformatted output unless rustfmt is explicitly selected and requires existing absolute workspace, destination and tool paths through their owning constructors.
Each process receives sixty seconds, five seconds for cleanup and 1 MiB per stream.
The aggregate allowance covers one formatter query, each permitted generated file and one compiler invocation.
Staging preserves the caller's publication byte allowance and adds the one authored fixture to its file allowance.
Destination inspection admits eight paths and 64 KiB, with 16 KiB of metadata.
These are explicit example limits, not library defaults or a new application configuration format.

The root [command owner](../../../src/native_publication/command/README.md) still owns preparation, compilation, installation and recovery.
