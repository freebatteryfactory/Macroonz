# Publication controls

This home observes root publication composition through its public API with an independently authored kind, addresses, stamp and expected values.
Inventory controls exercise complete sealed bindings, record/definition disagreement, named landings, path aliases and shared resource limits.

Native formatter controls execute the selected toolchain's rustfmt under an explicitly supplied configuration while a hostile ambient configuration is present.
Repeated generation and relocated inputs compare actual physical bytes and unchanged canonical commitments.
Independent compiled tool stand-ins exercise incomplete queries, failure, output floods, deadlines, invalid text, changed configuration and retryable cleanup.
Stand-in version strings are declared test inputs and do not authenticate real formatter behavior.
Prepared-set controls preserve complete output order, admit an empty publication and refuse missing, duplicate, foreign, failed, crossed-source and aggregate-oversized physical material.

Staging controls compile actual formatted files with Cargo and rustc, execute independently expected values and retain identical canonical and physical commitments across repeated generation and relocation.
An otherwise successful build that omits a prepared file refuses qualification, as does formatter output containing invalid Rust.
Complete-union bounds and path collisions refuse before staging, while changed, missing, extra, linked and non-file entries refuse before compiler startup.
The directory replacement control observes Windows handle exclusion and, on Unix, refusal of a changed visible source root.
Pending compiler cleanup retains the source context and compares it again after retry.
Staging alone grants no destination ownership or installation evidence.
The formatted-staging journey also installs its actually compiled physical set and verifies that authored fixture inputs are excluded from publication.

Destination controls independently construct historical ownership records and snapshot directories around read-only checks and refused changes.
Installation controls use actually compiled publications, preserve authored neighbors, regenerate twice, replace and retire owned output, repair missing files and reopen a relocated destination.
Recovery controls interrupt at each public file step, terminate a real installer process, restore journal-retirement boundaries and refuse damaged metadata, changed output and unexpected journal entries.
A retained temporary hard link and a partial incoming file cannot rewrite already installed output when installation resumes.
Directory/file links and changed filesystem kinds refuse without touching their external targets, and interrupted regeneration recovers every mixture of previous, new and retired owned paths.
Feature-isolated consumers observe private installation custody and consuming commit from outside the root crate.

Command controls compose the registered generator, formatting, checking, actual compilation and installation through the public root API.
They require aggregate process admission before effects, reject a workspace inside its destination including link aliases, retain workspace exclusion during pending cleanup, and recover historical intent without invoking generation.
Cached staging controls preserve exact identical inputs and refuse damaged, incomplete, extra or linked material without repairing it.
The executable example runs each selected action in a fresh process, checks the independently expected compiled value, and returns failure for missing, stale or tampered output while preserving authored neighbors.
The shared-definition example binds its complete stamp landings, reports stale second-site output and both tampered and stale first-site output, and compiles the actual installed files against independent literal value assertions.
It preserves authored fixtures and refuses regeneration over damaged owned files.
Independent consumers exercise the command and cached-stage entrances and refuse access to private command error and cleanup custody.
