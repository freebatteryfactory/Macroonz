# testpak seat 05 — fault (reserved)

**State: reserved.** This directory holds one file, and this is it. There is no
`mod.rs`, no type, no function, no public surface, and no obligation row standing
behind the name. `lib.rs` declares no module here, so nothing in this package can
reach this coordinate — it is a place in the map, and the map says so.

## The question this seat is reserved for

*What happens when the world underneath the machine misbehaves, and what does the
machine promise about it?*

The mutation seat damages an ARTIFACT and asks whether a judge notices. This seat
asks the other question: an effect that refuses, an acknowledgement that never
arrives, a resumption from a checkpoint that is older than the caller believed —
faults in the surroundings rather than defects in the output — and what the
machine states it holds to across each one.

## What it contains today

Nothing. No injector, no fault roster, no recovery challenge. The seat is a
coordinate with a question written on it.

## What materializes it

A machine seam that can actually experience a fault: an effect boundary, an
acknowledgement ladder, or a checkpoint-and-resume road that exists and states a
promise a fault could break. Damage aimed at a seam nobody has built lands on the
author's model of it, which is the correlated evidence this plane exists to
refuse.

## What this reservation does not claim

It does not claim an injector exists, is designed, or is specified beyond the
question above. It does not claim a fault roster, a recovery model, or any
promise on the machine's behalf. It does not claim the seat's number reserves any
dependency position: no module is declared, so no band edge exists to point
anywhere. And it does not claim that material which fails to fit this question
may be filed here anyway — in particular, artifact damage is the mutation seat's
and stays there.
