# testpak seat 02 — arena (reserved)

**State: reserved.** This directory holds one file, and this is it. There is no
`mod.rs`, no type, no function, no public surface, and no obligation row standing
behind the name. `lib.rs` declares no module here, so nothing in this package can
reach this coordinate — it is a place in the map, and the map says so.

## The question this seat is reserved for

*Where does hostile execution actually run, and what does one run report?*

The judge states verdicts and the corpus supplies populations; neither of them
says how a hostile run is set up, driven, bounded, and read back. This seat is
where that lives: the orchestration of a run over a population, the magnitudes
one run stands under, and the report a run produces — claim-specific and
method-specific, like every verdict in this plane.

## What it contains today

Nothing. No runner, no harness, no report type, no schedule. The seat is a
coordinate with a question written on it.

## What materializes it

The first hostile run that needs orchestration a test function cannot carry: more
than one population, a bound a run must be held to, or a report a reader consumes
apart from the assertion that produced it. Until then, every challenge in this
plane is one `#[test]` reading one input, and a runner over one case is
ceremony — cargo already owns that.

## What this reservation does not claim

It does not claim a runner exists, is designed, or is specified beyond the
question above. It does not claim a report shape, a scheduling model, or a
budget. It does not claim the seat's number reserves any dependency position: no
module is declared, so no band edge exists to point anywhere. And it does not
claim that material which fails to fit this question may be filed here anyway.
