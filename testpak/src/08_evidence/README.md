# testpak seat 08 — evidence (reserved)

**State: reserved.** This directory holds one file, and this is it. There is no
`mod.rs`, no type, no function, no public surface, and no obligation row standing
behind the name. `lib.rs` declares no module here, so nothing in this package can
reach this coordinate — it is a place in the map, and the map says so.

## The question this seat is reserved for

*What did a run actually establish, in a form somebody who did not watch it can
read?*

Seat 00 carries the denominators a verdict is stated over. This seat asks the
next question: what one executed run leaves behind — which claims it stood over,
by which method, against which population, with which magnitudes — so that a
reader holding the record can tell what was established from what was merely run.

## What it contains today

Nothing. No record type, no writer, no reader, no stored run. The seat is a
coordinate with a question written on it.

## What materializes it

A run whose result somebody has to read WITHOUT the run in front of them. While
every challenge is a `cargo test` invocation whose failure is its own report, a
record would be a second statement of what the first one already said — and a
second statement of a fact is a second thing to keep true. The seat opens when a
result outlives the process that produced it.

## What this reservation does not claim

It does not claim a record exists, is designed, or is specified beyond the
question above. It does not claim a format, a storage road, or a retention
posture. It does not claim any authority over what a verdict may say — that
belongs to seat 03, the judge. It does not claim the seat's number reserves any
dependency position: no module is declared, so no band edge exists to point
anywhere. And it does not claim that material which fails to fit this question
may be filed here anyway.
